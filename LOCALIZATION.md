# Localized TeslaMate Custom Dashboards

This fork keeps the upstream English dashboards unchanged and generates a
localized dashboard set at install/update time.

## Quick start

```bash
git clone https://github.com/SiNaPsEr0x/Teslamate-CustomGrafanaDashboards.git
cd Teslamate-CustomGrafanaDashboards
./scripts/localize.sh
```

Italian is generated by default. For another bundled language:

```bash
TESLAMATE_CUSTOM_LOCALE=de ./scripts/localize.sh
TESLAMATE_CUSTOM_LOCALE=fr ./scripts/localize.sh
TESLAMATE_CUSTOM_LOCALE=es ./scripts/localize.sh
```

Then use `scripts/docker-compose.yml` as the reference for the Grafana volume:
`.localized/${TESLAMATE_CUSTOM_LOCALE:-it}` is mounted at
`/TeslamateCustomDashboards`.

The installer/updater can also do the clone, update and generation in one step:

```bash
TESLAMATE_CUSTOM_LOCALE=it ./scripts/clonerepo.sh
```

See [`i18n/README.md`](i18n/README.md) for catalog format, validation rules and
how to add another language.
